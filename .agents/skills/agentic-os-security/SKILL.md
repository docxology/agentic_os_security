# agentic-os-security

## When to use

Load this skill whenever a task touches this project: editing `src/agentic_os_security/`, running the analysis or variables scripts, editing `manuscript/` sections, updating `data/claim_ledger.yaml`, or debugging tests/render.

## Quick reference

```bash
uv sync                                                   # install (project root, standalone)
uv run python scripts/00_preflight.py                     # environment checks
uv run python scripts/10_evaluation_analysis.py           # 6 figures + 4 data artifacts + validation report
uv run python scripts/z_generate_manuscript_variables.py  # {{TOKEN}} pipeline -> output/data/manuscript_variables.json
uv run pytest tests/ --cov=src --cov-fail-under=90        # ≥90% coverage gate
```

Render (from the **template repo root**, project linked under `projects/working/`):

```bash
uv run python scripts/pipeline/stage_03_render.py --project working/agentic_os_security
```

## Key facts

- Constants: 9 properties, 24 candidates, 8 scenarios, 7 trust domains, 9 controls, 9 invariants, 216 matrix cells, 65 + 6 = 71 bib keys, 6 figures, 18 sections. Single-sourced in `src/agentic_os_security/` registry modules — import, never restate.
- Stances: `strong | partial | weak | n_a`. Forecast confidence: `high | moderate | low`, horizon 2028–2031.
- Determinism: `build_clock.py` honors `SOURCE_DATE_EPOCH`; never wall-clock in artifacts; figures byte-identical across runs.
- Tokens: only from the plan in `docs/syntax_guide.md`; generated by `manuscript_variables.generate_variables()`.
- Layer rule: no `infrastructure` imports in `src/` (scripts only for the guarded template injection in the z-script).

## Pitfalls

- Editing anything under `output/` by hand — it is disposable; fix the generator and rerun.
- Adding a `{{TOKEN}}` not in the plan, or a citation key not in `references.bib` — tests fail (by design).
- Presenting vendor findings as independent measurements, or assigning numeric security scores — attribution discipline forbids both.
- Publishing actions (DOI, Zenodo, uploads) — the project is private; owner ask required.
- Adding mermaid to `manuscript/` — forbidden; the render chain must stay diagram-tool-free.
