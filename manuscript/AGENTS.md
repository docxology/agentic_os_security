## `{{VARIABLE}}` protocol

- Tokens appear **only** from the token plan (`docs/syntax_guide.md`); never invent a token.
- Authoritative source: `src/agentic_os_security/manuscript_variables.py::generate_variables()`; generation command: `uv run python scripts/z_generate_manuscript_variables.py` (writes `output/data/manuscript_variables.json`; injects the resolved tree when a template repo parent is detected).
- Unresolved/invented tokens are caught by `tests/test_manuscript_variables.py` (every `{{X}}` in `manuscript/*.md` must resolve).
- Counts in prose must match the registry constants (9 properties, 24 candidates, 8 scenarios, 7 trust domains, 9 controls, 9 invariants, 216 cells, 65 sources, 6 figures). Use the `{{CONFIG_*}}`/`{{RESULT_*}}` tokens where a count appears.

## RASP + attribution conventions

- No "In summary"/"In conclusion" closers; active voice; concrete paths; one idea per paragraph; no filler.
- Analytical judgments from documented designs — never implied penetration testing; vendor findings labeled as vendor findings; forecasts distinguished from measurements; **no numeric security scores**.
- Citations only `[@key]` with keys from `references.bib`; cross-refs only `[@sec:...]`/`[@fig:...]`/`[@tbl:...]`; every H1 carries its pinned `{#sec:...}` label.
- **No mermaid fences** in any `manuscript/*.md` (render prerequisite is deliberately zero diagram tooling).

## Section modification workflow

1. Edit the section source (`NN_name.md`) — respecting the H1/label and conventions above.
2. If prose references new numbers: register them in `data/claim_ledger.yaml`; if they come from code, update the registry module, not the prose constant.
3. Regenerate: `uv run python scripts/10_evaluation_analysis.py` (if registry/figure content changed), then `uv run python scripts/z_generate_manuscript_variables.py`.
4. Verify locally: `uv run pytest tests/ --cov=src --cov-fail-under=90` (structure, token, parity tests run against the real files).
5. Render **from the template repo** (`projects/working/` link): `uv run python scripts/pipeline/stage_03_render.py --project working/agentic_os_security`.

Never edit the resolved/hydrated tree in the template environment; it is generated.
