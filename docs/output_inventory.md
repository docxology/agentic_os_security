Everything below is generated by `uv run python scripts/10_evaluation_analysis.py` (figures + data artifacts) and `uv run python scripts/z_generate_manuscript_variables.py` (variables JSON). Nothing here is hand-maintained.

## Data artifacts — 8 in `output/data/` (plus the variables file)

| Artifact | Content | Rows/shape |
|---|---|---|
| `evaluation_matrix.csv` | Candidate × property stances: `candidate_id, candidate_name, property_id, stance` | 216 rows (24 candidates × 9 properties), 100% coverage |
| `scenario_recommendations.csv` | One recommendation per scenario: `scenario_id, situation, recommendation, change_condition` | 8 rows |
| `evidence_summary.json` | Source-tier counts (official / advisory / incident_report / research / community) + the capability baseline constants | single object |
| `validation_report.json` | Self-checks: matrix completeness, stance vocabulary, source-URL parity with the registry, forecast counts | all-green object |
| `defensive_stack.csv` | Candidate × mitigation-class stances: `candidate_id, class_id, stance` | 192 rows (24 candidates × 8 mitigation classes) |
| `update_windows.csv` | Documented support/update policies: `candidate_id, policy, months` | 24 rows |
| `incident_register.csv` | Documented platform and agent incidents: `incident_id, date, actor_class, vector, boundary_lesson, citation` | 14 rows (from `evidence.INCIDENTS`) |
| `cognitive_defenses.json` | Cognitive Integrity Framework (CIF) concepts mapped to controls and section labels: concept → summary → surface → citation key | 6 concepts (from `orchestration.CIF_CONCEPTS`) |

Plus, from the variables script:

| Artifact | Content |
|---|---|
| `manuscript_variables.json` | Every `{{TOKEN}}` → value (token plan in `docs/syntax_guide.md`); written by `z_generate_manuscript_variables.py`; requires the four analysis outputs to exist |

## Reports — `output/reports/`

Human-readable run summaries (analysis run metadata, artifact hashes, `build_clock.py` timestamps honoring `SOURCE_DATE_EPOCH`).

## Regeneration commands

```bash
uv run python scripts/00_preflight.py                   # environment sanity first
uv run python scripts/10_evaluation_analysis.py          # 9 figures + cover graphical abstract + 8 data artifacts + validation report
uv run python scripts/z_generate_manuscript_variables.py # manuscript_variables.json (+ template injection when detected)
```

If any artifact is missing, stale, or non-deterministic, do not patch it — fix the generator in `src/` and regenerate.
