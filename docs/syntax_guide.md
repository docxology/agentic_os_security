# syntax_guide.md — manuscript syntax and token plan

`manuscript/` is Pandoc markdown rendered by the sibling template repository. This page pins the syntax: citations, cross-references, section labels, and the `{{TOKEN}}` plan.

## Citations

- Pandoc syntax only: `[@key]`, `[@key1; @key2]`, narrative `@key did X`.
- Keys come **only** from `manuscript/references.bib` (155 source-derived + 13 scholarly = 168). Never raw `\cite{...}` or `\ref{...}`.
- Bibliography is generated by Pandoc–natbib; `99_references.md` contains no hand-written entries.

## Cross-references

- Sections: `[@sec:name]` — labels are pinned per file, e.g. `# Introduction: Agents Arrive at the Kernel Boundary {#sec:introduction}`. Every H1 carries its label; the abstract's H1 is exactly `# Abstract {#sec:abstract}`.
- Figures: `[@fig:evidence_timeline]` … labels are pinned in the figure registry (`docs/output_inventory.md`).
- Tables: `[@tbl:properties]`, `[@tbl:offensive_evidence]`, `[@tbl:qubes_limits]`, `[@tbl:nixos_misconceptions]`, `[@tbl:desktops]`, `[@tbl:servers]`, `[@tbl:comparators]`, `[@tbl:trust_domains]`, `[@tbl:controls]`, `[@tbl:invariants]`, `[@tbl:scenarios]`, `[@tbl:confidence]` — pandoc-crossref `{#tbl:...}`.
- Never literal "Figure 3" or "Section 4" — always cross-reference.

## Figures

```markdown
![caption text](../output/figures/<file>.png){#fig:<label> width=100%}
```

## Generation and checking

```bash
uv run python scripts/z_generate_manuscript_variables.py   # writes output/data/manuscript_variables.json; injects when template repo detected
```

The unresolved-token check is enforced by `tests/test_manuscript_variables.py`: every `{{X}}` appearing in `manuscript/*.md` must resolve via `generate_variables()`.

## Prohibitions

- No mermaid blocks anywhere in `manuscript/*.md` (the render chain has no diagram prerequisite; this project avoids mermaid in the manuscript).
- No hand-written bibliography entries in `99_references.md`.
- No numeric security scores in any table or prose — qualitative stances only (`strong | partial | weak | n_a`).
